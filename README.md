# fewvar.github.io

Одностраничная витрина-портфолио. Чистый HTML, CSS и JavaScript — без фреймворков,
сборщиков и зависимостей.

**Живая версия:** https://fewvar.github.io

## Что внутри

```
index.html    разметка и весь текст
styles.css    стили, палитра в CSS-переменных
main.js       появление блоков при скролле, состояние шапки
assets/       изображения
```

## Как устроено

- **Адаптив** — от 320 px до широких мониторов, сетки на CSS Grid, размеры через `clamp()`.
- **Анимации** — появление секций через `IntersectionObserver`, всё остальное на CSS.
  Уважается `prefers-reduced-motion`; без JavaScript контент виден полностью.
- **Палитра** — монохром с одним пурпурным акцентом, задана переменными в `:root`.
- **Шрифты** — Unbounded (заголовки), Golos Text (текст), JetBrains Mono (подписи),
  все с поддержкой кириллицы.

## Локальный запуск

```bash
python3 -m http.server 8000
```

Открыть http://localhost:8000

## Деплой

GitHub Pages из ветки `main`, корень репозитория. Пуш в `main` обновляет сайт.
